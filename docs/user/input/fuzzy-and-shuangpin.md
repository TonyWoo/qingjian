## 模糊音

九条：z/zh、c/ch、s/sh、n/l、f/h、l/r、an/ang、en/eng、in/ing。缺省全部关闭。

开启：输入法菜单「模糊音」子菜单勾选，或「偏好设置 → 模糊音」。开启 z/zh 后输入 `zi` 也出 知 / 之，开启 f/h 后输入 `kaiha` 也出 开发。
输入正确的词仍然优先，模糊匹配的词排在其后。韵母三条只对完整音节生效。

## 输入方案

在「偏好设置 → 通用 → 输入方案」里选，缺省是全拼。可选：全拼、小鹤双拼、自然码、微软双拼、搜狗双拼、大千注音、五笔（86 版）。

中英切换始终是 `Shift`，与选哪套方案无关。全拼、双拼与注音都是「拼音」的读法，共用同一份词库、整句转换与学习数据；五笔是形码，见下一节。

## 双拼

四套方案：小鹤、自然码、微软、搜狗。

- 拼音行显示解出的全拼（`nihc` → `ni'hao`），学习按全拼记录，切回全拼后同样受益。
- 零声母：小鹤 / 自然码写 `aa` `ai` `ah`（a、ai、ang）一族；微软 / 搜狗写 `o` + 韵母键（`oa` `ol` `oh`）。
- 微软 / 搜狗的 `;` 为 ing：输入拼音时末尾有落单的声母，`;` 作为拼音（`x;` → xing）；其他情况下仍为标点。
- 双拼下 v / u / i 均为音节键，[快捷输入](shortcuts.md) 中的算式与问字只能以 `?` 开头进入。
- 全拼输入 `lue` / `nue` 与词库形式 `lve` / `nve` 等价。双拼统一解为 `lve` / `nve`。
- 已知限制：`lo` 与 `luo` 同键，解为 luo。

## 五笔（形码）

86 版五笔。敲的是字根编码而不是读音：`ggll` 出 一，`khlg` 出 中国，`gant` 出 开发。
候选框顶部原样显示敲的编码，不打乱成音节。

- 编码打到哪儿算哪儿，按该前缀查表。编码正好打全的词排在同前缀的更长编码词前面（这就是一级 / 二级 / 三级简码）。
- 空格上屏高亮候选，数字键选词，与拼音一致；候选旁的译文、词频学习与生词记录也照常。
- 这条路上没有拼音的那些能力：整句输入、简拼、模糊音、拼写纠错、中英混输，以及 `v` / `u` / `i` 开头的[快捷输入](shortcuts.md)。
  这三个键在五笔里是字根键，不再当模式键。
- 拼音方案下的学习数据与五笔互不影响，两边的选择各记各的。
